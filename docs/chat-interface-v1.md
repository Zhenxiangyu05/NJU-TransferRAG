# 连续聊天界面 v1

基于上线78f1bde，仅改公众前端及其测试。后端JAR、接口、多轮补全/最近4轮/30分钟TTL、官方Chat、学校bge-m3、缓存/Lua/Resilience、Worker=false、知识库及公开授权不变。没有付费模型调用或数据库迁移。

## 行为与边界

- 复用App、AnswerPanel、AskForm、SourceCard和conversationClient；问题立即加入同一聊天区，答案、等待、错误/澄清归属于对应问题。本页全部消息保留，直到新对话、刷新或关闭；不做持久存储、历史列表或长期记忆。
- 输入区是可滚动区域外的固定布局兄弟元素，不覆盖最后一条消息。桌面和手机适配，使用visualViewport高度响应键盘占用；不主动弹出键盘。
- 接近底部（96px）时跟随；向上翻阅则保留可见消息锚点，新消息/引用展开不强拉底部，提供回到底部。只由真实滚动手势改变跟随意图，不把布局/焦点/高度变化的scroll事件当作上翻。
- 新对话立即清屏并使旧请求结果失效，等待原请求结束后使用既有服务端重置。不中止HTTP来假装服务端已取消。重置失败阻止新问题，明确提示再次重置；不将空窗口连回旧历史。没有自动重试或额外模型调用。
- 页面记录不等于模型上下文；旧消息可翻阅但模型仍受既有限制。大量页面消息会消耗浏览器内存，不实现虚拟列表或压缩摘要。

## 参考文档与安全

每条回答按documentId去重，保留所有原始citationId、Chunk和页码；正文[Sx]跳转到本条回答自己的来源锚点，避免多轮相同编号串联。标题只使用返回字段，缺失时明确未提供，不编造标题。

后端fileAvailable仅表示文件存在，不是公开许可。前端复用GET /api/public/sources/{id}做只读元数据核验，AVAILABLE/DOWNLOADABLE且匹配ID/格式才显示既有/sources/{id}阅读路由。每文档并发合并，30秒短期核验、上限100项；不为引用展示下载原文文本或PDF。最终原文请求仍由后端独立重新授权。失败/私有/未知/整理知识无原文链接，保留引用和来源类型。每个引用保留各自页码的合法链接。

不信任模型生成的任意URL或sourceUrl作为原文授权；Markdown仅保留安全文字及本轮有效引用导航，不加载外部图片/媒体或管理链接。所有标题和用户输入按Vue文本转义，Markdown继续DOMPurify净化。

本地previewChat.mjs仅拦截到隔离合成API，无模型/生产服务。真实浏览器验证桌面1366×1000、手机390×844、缩小390×450：无横向溢出、输入区可见、跟随正确。缩小视口是键盘占用模拟，不冒充实体手机软键盘验收。实际浏览器10轮保留、上翻时新增消息保持scrollTop=0、回到底部、正文引用关联、私有文档无链接及新对话竞态通过。截图仅合成资料，不包含私人文档或真实AI回答。

独立提交、干净git archive构建，仅发布公众前端index.html及新hashed assets，保留生产ICP等公开构建配置，不改隐私正文、不更新管理端、不重启任何服务。旧静态目录先在root-only备份目录打包并校验。先放assets再原子替换index，保留旧assets避免已打开页面失效。
